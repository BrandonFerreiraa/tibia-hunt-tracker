## Story
**As a** jogador de Tibia com sessões registradas,
**I want** ver minhas sessões em uma lista clara, com detalhes de monstros e itens sob demanda,
**so that** eu consiga revisar rapidamente o desempenho de cada hunt sem poluir a tela.

## Acceptance Criteria
1. Given um personagem com sessões salvas, When a lista carrega, Then cada card mostra nome da hunt, data, duração, profit (balance) e XP/h — ordenados do mais recente para o mais antigo.
2. Given um card de sessão, When o usuário clica para expandir, Then vê a lista de monstros mortos (nome + quantidade) e itens lootados (nome + quantidade) daquela sessão especificamente.
3. Given uma sessão sem monstros/itens registrados (ex: veio do formulário manual), When expandida, Then mostra uma mensagem indicando que não há esses dados, sem erro.
4. Given múltiplas sessões na lista, When uma é expandida, Then as outras permanecem no estado que estavam (expansão é independente por card).

## Complexity
T-shirt size: **S** — é essencialmente completar o `SessionList.jsx` já iniciado na Story 1.3 com expansão e busca sob demanda.

## Business Value
Fecha o Epic 1 (MVP funcional) — sem isso, os dados detalhados (monstros/itens) ficam presos no banco sem forma de consulta pela UI.

## Risks
- **Buscar monstros/itens de todas as sessões de uma vez** seria desperdício se o usuário nunca expandir a maioria — mitigado por busca sob demanda (lazy, só ao expandir).
