## Story
**As a** jogador de Tibia usando o Hunt Tracker,
**I want** ter uma conta própria com meus personagens e sessões isolados dos de outros usuários,
**so that** eu possa registrar minhas hunts com segurança e privacidade, sem ver ou expor dados de outras contas.

## Acceptance Criteria
1. Given um usuário não autenticado, When acessa o site, Then é redirecionado para login/signup.
2. Given um usuário autenticado A, When consulta `sessions`, Then só vê registros de personagens vinculados à sua conta (RLS testado com 2 contas).

## Complexity
T-shirt size: **M** — setup de infraestrutura (projeto Supabase, schema, RLS) + tela de auth simples, sem lógica de negócio complexa.

## Business Value
Sem isso, nenhuma outra story do Epic 1/2 é possível — é a base de dados e autenticação que todo o resto do produto depende (personagens, sessões, verificação, feed).

## Risks
- **RLS mal configurada** expõe dados entre contas — mitigado pela Task 5 (validação manual com 2 contas antes de considerar a story pronta).
- **Chaves Supabase commitadas por engano** — mitigado por `.env` já no `.gitignore` (confirmado na instalação do AIOX).
