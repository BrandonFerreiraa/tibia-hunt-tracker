## Story
**As a** jogador de Tibia autenticado com um personagem ativo,
**I want** colar o texto do Session Analyser (ou preencher manualmente) e nomear a hunt,
**so that** minha sessão seja registrada com todos os dados relevantes, sem digitar tudo campo por campo.

## Acceptance Criteria
1. Given o usuário cola o texto do analyser no formato padrão do jogo, When confirma, Then todos os campos (duração, XP, raw XP, loot, supplies, balance, damage, healing, monstros mortos, itens) são extraídos e exibidos numa prévia editável antes de salvar.
2. Given o parser não reconhece o texto colado (formato inesperado), When o usuário tenta usar o parser, Then é oferecido o formulário manual, sem perder o texto colado.
3. Given qualquer fluxo (parser ou manual), When falta o campo "Nome da hunt", Then o formulário bloqueia o salvamento com mensagem clara.
4. Given nenhum personagem está selecionado como ativo, When o usuário acessa o formulário de sessão, Then é orientado a cadastrar/selecionar um personagem primeiro (não pode salvar sessão "solta").
5. Given uma sessão é salva com sucesso, When o usuário revisita a página, Then a sessão aparece numa lista simples (versão completa/expansível fica pra Story 1.4).

## Complexity
T-shirt size: **L** — parser de texto com múltiplos formatos de linha (cabeçalho, monstros, itens), form de preview editável, fallback manual.

## Business Value
É o coração do produto — sem isso, o Hunt Tracker não registra hunts de verdade.

## Risks
- **Parser frágil a variações de idioma/formatação** do client do Tibia — mitigado por: fallback manual sempre disponível (AC 2), e o parser é tolerante a variações razoáveis (espaços, mas não tenta suportar outros idiomas nesta story).
- **Perda de dados digitados** se o parse falhar — mitigado por manter o texto colado visível ao cair no modo manual.

## Dev Notes

**Formato de referência do Session Analyser (exemplo real fornecido pelo usuário):**
```
Session data: From 2026-08-26, 06:44:35 to 2026-08-26, 09:23:08
Session: 02:38h
Raw XP Gain: 18,005,805
XP Gain: 18,005,805
Raw XP/h: 6,812,273
XP/h: 6,812,273
Loot: 7,320,378
Supplies: 1,085,048
Balance: 6,235,330
Damage: 24,231,461
Damage/h: 9,168,592
Healing: 4,838,936
Healing/h: 1,830,935
Killed Monsters:
  854x demon
  662x grimeleech
Looted Items:
  1153x a great mana potion
  105450x a gold coin
```
- Datas no formato `YYYY-MM-DD, HH:MM:SS`. Duração (`Session: HH:MMh`) pode ser recalculada a partir de `ended_at - started_at` em segundos (mais confiável que parsear "02:38h").
- Números usam `,` como separador de milhar — remover antes de `parseInt`.
- Seção "Killed Monsters:" e "Looted Items:" têm linhas no formato `  NNNx nome do item ou monstro` (nome pode ter espaços).

**Contexto (de [Epic 1](epics/epic-1-core-hunt-tracking/epic.md), Story 1.1, Story 1.2):**
- Tabelas `sessions`, `session_monsters`, `session_items` já existem com RLS (Story 1.1).
- `src/hooks/useCharacters.js` expõe `activeCharacterId` — usar para vincular a sessão.
- Esta story **remove** o fluxo antigo de `localStorage` ([src/components/HuntForm.jsx](../../src/components/HuntForm.jsx), [HuntList.jsx](../../src/components/HuntList.jsx)) — ele já cumpriu seu propósito de placeholder inicial do projeto.
